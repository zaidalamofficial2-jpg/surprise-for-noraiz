# ZA CMA Learning Hub — GitHub Upload

This ZIP contains the updated website entry file and deployment instructions.

## Files

- `index.html` — updated ZA CMA Learning Hub website.
- `README.md` — these instructions.

## Publish on GitHub Pages

1. Download this ZIP and extract it on your device.
2. Open your existing `LMS-Project` GitHub repository.
3. Before replacing anything, keep a backup copy of your current `index.html`.
4. Upload the extracted `index.html` to the **same repository location** as the existing homepage (usually the repository root).
5. Choose **Commit changes** to save the update.
6. Wait for GitHub Pages to finish publishing, then open the website and refresh it. If an old version still appears, try a hard refresh or clear the browser cache.

## Important

- Do **not** upload the ZIP file itself as the website homepage. Extract it first and upload `index.html`.
- Replace only the intended homepage file. Do not delete other folders, assets, or project files from the repository.
- Keep any existing repository files that the project uses.
- The Mock Tests section is inside **Practice**. It displays the subject cards and a “Coming soon” notice; mock-test questions and test materials have not been added yet.
- The existing ICMA Library / Google Drive links are intended to remain available. Check the library and its external Drive link after deployment.

## After publishing — quick check

- Open the homepage on a phone and a computer if possible.
- Open **Practice** and confirm the Mock Tests section appears.
- Open **ICMA Library** and test the Google Drive link.
- Try one existing practice activity to confirm the rest of the site still works.
